### 冲动消费
如果买一个东西的时候很匆忙，而且没有经过细致的对比、选择、看评测，那么 99% 买回来是会后悔的。只是觉得「设计我还挺喜欢的」解决不了任何实际的问题。自警了。不过这周也是买到了好东西的——一副有线耳塞。主要是为了玩 Switch 的时候可以不用经过外接屏的扬声器、同时又不用把插在机箱后面的耳机反复插拔的情况下，直接通过外接耳机来听声音。始终信奉一点：玩游戏不听声音，不如不玩。

### 游戏、音乐和其他
尽管通关《异度之刃 3》已经是去年的事了，但还是不时会去重听 OST。这一部对笛子的利用真的是非常让人着迷，而音乐和游戏场景、故事设计的结合又赋予了音乐和画面极强的感染力。真希望能有更多人体验到这部作品。

上下班路上一直听自己整理的歌单 “Pocket”，风格比较杂乱——基本上是围绕 ACG 音乐 + 各类型都涉及。看有人说，品味是歌单里水平最低的曲目决定的，那显然我是个非常没有水平的人，音乐品味非常之差。

周三左右开始，每晚重新拿起了火纹结合。自己选的经典模式 + 困难，怎么也得打下去。随着玩随着查相关教程、资料，也磕磕绊绊玩了下来。如果有机会应该会买《风花雪月》，而至于更早期的几部，就看缘分了。这几天正好看到 Switch 2 公布了，不知道自己会哪年买。毕竟今年还有点眼馋 Steam Deck。

又开始听音声了。发现这东西确实，有点，难以摆脱。哈哈。

### 阅读和观影
这周工作比较恼人，而且年前也静不下心，所以一直在一本书上原地踏步。依旧在读《履单》。电影、电视剧和番剧就更不用说了，是完全没有进度的。正好过年回家可以消磨时间。

### 其他的一些想法
今天看到存的龙虾教授的写作指南，突发奇想上网搜了下中文的写作指南。发现除了程序员写的文档写作规范和规范具体格式的文档，几乎没有一篇简洁、可读性强的中文写作指南。希望能有人做这件事吧，毕竟如果是别的小事我会心血来潮去做，但这样专业性强的事情，实在是不敢轻易越俎代庖。但自己能做的事也有——在自己写的内容里，采用一致的「标准」：

- 在中文和英文、数字之间保留一个半角空格
- 数字和单位之间空格
- 正确使用「的、地、得」
- 在一篇文章内采用一致的标点习惯（例如，使用哪种引号、使用全角还是半角标点）

之所以给「标准」加了引号，是因为这其实不是一个标准，只是要求自己保持的规范。说来也是缘分，如果不是做了本地化行业的工作，我自己也不会非常注意这些标点、空格之类的细小规则。就如同并不是所有学了英语的人都知道英文标点有一系列相应的标点规范、短横还分 en、em、hyphen 等几种一样，这些小问题其实也可以被当作一种穷酸书生的矫情，但如果把一切认真都下意识斥为「矫情」，也未免有刻奇之嫌。

我自己并不是一个喜欢「规定」的人，我更喜欢「规则」。两者的差别是，前者带有一种高高在上的强加感，后者则更倾向于一种约定。而且也并不是一切「规则」我都会毫不犹豫地采用。那些能够带来良好体验的、让文字、画面等变得更加赏心悦目——至少效果上让我感到愉悦——的规则，我就会自己去尝试遵循。比如 Git Commit 究竟该怎么写，区区一个博客有没有必要邯郸学步跟着搞一套规范的 Commit Comment？前两天因为一篇文章了解到了「[约定式提交](https://www.conventionalcommits.org/zh-hans/v1.0.0/)」之后，就也用 GitHub Desktop 做了 Squash，重新整理了博客过往的 Commit。完成后至少一眼看上去自己也能想起每一次提交是改动了什么，比起之前 Update、update、更新、修改……这类随便写的东西要好得多。

另：在 Google 自搜博客文章的时候，发现[《角色们在唱什么？关于〈日常〉的片尾曲》](https://www.hanbun-hoshi.top/posts/nichijou_ending_songs/)这篇不需要再重定向了，真是让人欣慰。希望之前那几篇都能早日不用重定向。前两天偶然发现了一位很有趣的博主，进行了一点点的评论交流。晚些提交了萌 ICP，没想到两天就通过了。
